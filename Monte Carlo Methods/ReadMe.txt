Monte Carlo Methods Project - Pricing Asian Options : In this project, we have done Monte Carlo for arithmetic Asian options with fixed strike and demonstrated the power of control and antithetic variates. We have chosen Geometric Asian and European for control variates. Naturally, the stock follows GBM, which makes the computation of the control variates feasible.

Use of AI Tools while coding: For this project ChatGPT wasn't used except for syntax verification. The programming was done in Visual Studio Code which was useful for autocomplete of some functions. From earlier iterations ( of other case studies ), it was decided that we shall describe the purpose of the functions using double quotes or hash in the beginning of the code block or after defining the function.
